An advanced, multimodal Retrieval-Augmented Generation (RAG) platform designed to process, index, and query Ancient Egyptian historical artifacts and authoritative academic texts. Powered by **Llama 3.2 11B Vision-Instruct**, **ChromaDB**, and **CLIP-based cross-modal projections**, this system bridges real-world physical museum artifacts with verified knowledge graphs
